# Plan 02-02: Deduplication & Profile-Driven Relevance Scoring Engine

## Objective
Upgrade `RecommendationService` to aggregate Adzuna + Jobicy, eliminate duplicates, and score jobs using an evaluated formula based on the user's `preferredCareer`, `interests`, and `goals`.

## Tasks

<task id="task-1">
  <name>Enhance KeywordUtil with multi-factor scoring and deduplication</name>
  <description>
    Update `backend/src/main/java/com/realmcheck/backend/util/KeywordUtil.java`:
    - Add `public static String generateDeduplicationKey(String title, String company)`: cleans whitespace, punctuation, and lowercases.
    - Add `public static double computeScore(Set<String> skills, String preferredCareer, String jobTitle, String jobDescription, String location, List<String> matchedTerms, StringBuilder explanation)`:
      - Role/Title score (0.0 to 0.30): exact or partial match of preferred career in title.
      - Skill score (0.0 to 0.50): proportion of matched skill terms found in title or description.
      - Location/Eligibility score (0.0 to 0.20): match for user location, "Remote", or "Worldwide".
      - Produce human-readable explanation string in `explanation`.
  </description>
</task>

<task id="task-2">
  <name>Update RecommendationService to aggregate sources, deduplicate, and score</name>
  <description>
    Update `backend/src/main/java/com/realmcheck/backend/service/RecommendationService.java`:
    - Inject `JobicyService` in addition to `AdzunaService`.
    - Retrieve user profile: `preferredCareer`, `interests`, `goals`.
    - If user keyword/career exists, query both `adzunaService.searchJobs(keyword, location)` and `jobicyService.searchJobs(keyword, location)`.
    - Deduplicate results by composite key.
    - Score each job dynamically with `KeywordUtil.computeScore`.
    - Sort jobs descending by score.
  </description>
</task>

<task id="task-3">
  <name>Add unit tests for scoring and deduplication</name>
  <description>
    Update `backend/src/test/java/com/realmcheck/backend/service/RecommendationServiceTest.java`:
    - Add test for cross-source deduplication (Adzuna + Jobicy returning same job title & company).
    - Add test for transparent scoring formula verifying computed weights (title + skills + remote eligibility).
    - Verify score explanation strings and matched terms list.
  </description>
</task>

## Verification
- Run backend tests: `cd backend && .\mvnw.cmd test -Dtest=RecommendationServiceTest`
- Ensure all tests pass with zero failures
