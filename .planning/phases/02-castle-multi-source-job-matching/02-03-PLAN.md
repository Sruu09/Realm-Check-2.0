# Plan 02-03: Castle Search & Recommendation UI Unification & Verification

## Objective
Unify the search and recommendation views in `Castle.tsx` so search queries benefit from the multi-source aggregation and relevance matching engine, while preserving existing save and application tracking functionality.

## Tasks

<task id="task-1">
  <name>Support parameterized multi-source search endpoint</name>
  <description>
    Update `backend/src/main/java/com/realmcheck/backend/controller/RecommendationController.java`:
    - Add/update `GET /api/recommendations/jobs`: accept optional query params `@RequestParam(required = false) String keyword, @RequestParam(required = false) String location`.
    - Pass query filters down into `recommendationService.getRecommendations(keyword, location)`.
    - Update `frontend/src/services/RecommendationService.ts`:
      - Update `getRecommendations(keyword?: string, location?: string): Promise<RecommendationDTO[]>`.
      - Update `RecommendationDTO` interface to include `source?: string; salary?: string; jobType?: string;`.
  </description>
</task>

<task id="task-2">
  <name>Enhance Castle.tsx UI with unified matching badges and source tags</name>
  <description>
    Update `frontend/src/pages/Castle.tsx`:
    - In `handleSearch`, query `getRecommendations(keyword, location)` to display unified multi-source, scored jobs.
    - Render job cards with:
      - Job title, company, location, salary.
      - Source badge (`Adzuna` / `Jobicy`).
      - Relevance score badge: green for >=80%, yellow for 50-79%, neutral for <50%.
      - Matched skill pills.
      - Plain-language match explanation.
      - Working "Apply" link opening in new tab (`rel="noreferrer"`).
      - "Save" button saving the job to `/api/saved-jobs` as before.
    - Ensure Saved Jobs, Applications, and Recommended tabs retain full functionality.
  </description>
</task>

<task id="task-3">
  <name>End-to-End Runtime Verification</name>
  <description>
    Verify end-to-end functionality:
    - Test backend builds: `mvnw.cmd test`
    - Test frontend builds: `npm run build`
    - Verify search with "Java", confirm results from multiple sources, non-hardcoded scores, working Save Job action, and valid Apply URLs.
  </description>
</task>

## Verification
- Verify backend builds clean on port 8081: `mvnw.cmd test-compile`
- Verify frontend builds without type errors: `cd frontend && npm run build`
- Manual or scripted check of `/api/recommendations/jobs?keyword=Developer`
