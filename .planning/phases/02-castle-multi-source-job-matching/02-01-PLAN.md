# Plan 02-01: Multi-Source Job Ingestion & Normalization Engine

## Objective
Implement public remote job fetching from Jobicy (`https://jobicy.com/api/v2/remote-jobs`) alongside Adzuna, normalizing both sources into an enhanced `RecommendationDTO` contract.

## Tasks

<task id="task-1">
  <name>Create JobicyService</name>
  <description>
    Create `backend/src/main/java/com/realmcheck/backend/service/JobicyService.java`:
    - Inject `RestTemplate`
    - Implement `public List<RecommendationDTO> searchJobs(String keyword, String location)`:
      - Call `https://jobicy.com/api/v2/remote-jobs` with query params `count=20` and optional `tag` or `geo`
      - Handle exceptions defensively (return Collections.emptyList() on network/parsing failure)
      - Map Jobicy JSON fields: `jobTitle` -> title, `companyName` -> company, `jobGeo` -> location, `url` -> url, `jobType` -> type, `annualSalaryMin` -> salary, `jobDescription` -> description
      - Set `source` field to "Jobicy"
  </description>
</task>

<task id="task-2">
  <name>Enhance RecommendationDTO contract</name>
  <description>
    Update `backend/src/main/java/com/realmcheck/backend/dto/RecommendationDTO.java`:
    - Add fields: `private String source;`, `private String salary;`, `private String jobType;`
    - Add getters and setters for all new fields
    - Ensure backwards compatibility with existing constructors and Jackson serialization
  </description>
</task>

## Verification
- Run backend compile: `cd backend && .\mvnw.cmd test-compile`
- Execute a direct test or curl check to verify Jobicy serialization
